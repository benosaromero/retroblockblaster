Instructions

Enter one compound in SMILES format and provide the email address where you would like to receive the results. Retro-Blockblaster analyzes the submitted structure against UCSF Chemistry Commons reaction data and returns possible retrosynthetic reaction routes, associated synthons, and building-block candidates.

After submitting, please wait while the job runs. When complete, results will appear on the page and a downloadable ZIP file will be emailed to you.

Use "Find more info" under a synthon to view matching building blocks from the database. The Tc score shows the Tanimoto similarity between each candidate building block and the original building-block fragment from the submitted molecule; higher scores indicate greater structural similarity.

Enumeration lets you test whether selected building blocks can be combined through a predicted reaction route to generate a possible product. To manually enumerate, choose one building block from each required synthon column. Once all required building blocks are selected, the tool will automatically attempt to generate the enumerated product and display the result.

Use "Enumerate All Shown Blocks" to automatically test every possible combination among the building blocks currently displayed for that reaction route. For example, if 10 building blocks are shown for Synthon 1 and 10 are shown for Synthon 2, the tool will test 100 possible combinations.

For best results, submit one valid SMILES string at a time. Large enumeration jobs may take longer depending on the number of building-block combinations.
